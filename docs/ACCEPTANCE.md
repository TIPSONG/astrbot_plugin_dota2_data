# 待执行验收清单

**所有项目均尚未执行。** 用户本轮要求只编写源码，不安装、不测试。本文件仅记录后续需要验证的事项；不提供已通过的结论，也不配置自动运行的 CI。

## 加载与面板

- [ ] 在隔离的 AstrBot 环境中加载插件，核对当前版本的工具及视图 API 兼容性。
- [ ] 面板只能通过有效 Dashboard 登录态访问敏感管理功能。
- [ ] 概览在尚未发起请求时不显示虚构的“在线”状态。
- [ ] 设置保存后重新读取一致；插件重载后仍然保留。
- [ ] API Key 不出现在面板读取响应、日志或查询历史中。
- [ ] 手机窄屏与桌面宽屏的面板布局、加载状态和失败提示可用。

## 对话与人格

- [ ] 安装、查询、保存配置和卸载前后，原人格正文保持一致。
- [ ] 普通闲聊不触发 Dota 数据请求，也不产生插件主动消息。
- [ ] “闲聊 → 查询战绩 → 继续闲聊”仍走原人格、原历史与原有陪伴流程。
- [ ] 当前实际提供商能调用工具并读取返回数据，不出现双重回复。
- [ ] 与 AntiPromptInjector、记忆和陪伴插件一起启用时没有工具结果误拦或上下文冲突。
- [ ] 外部昵称等数据不能让模型或插件执行其中嵌入的指令。

## 绑定与权限

- [ ] Dota32 与 Steam64 的转换、非法 ID 拒绝及输入边界正确。
- [ ] 聊天工具只能改变当前发送者自己的绑定。
- [ ] 绑定／解绑需要下一条明确确认；过期、重载或其他用户的确认不能执行待办。
- [ ] 不同群聊／私聊之间没有隐式串用绑定或别名。
- [ ] 未绑定本人、别名重复和无效账号均返回明确的澄清或错误。
- [ ] 面板修改与删除绑定后再次读取一致，解除绑定不删除缓存之外的其他数据。

## 数据正确性

- [ ] 日期窗口正确处理香港时区的午夜、周界和月界。
- [ ] 英雄、胜负、模式及时间筛选组合后，数量上限作用在符合条件的结果上。
- [ ] 分页、扫描上限、缓存与时间范围缺失时的覆盖提示准确。
- [ ] 胜率、均值、样本量与共同对局交集能与原始样本逐项核对。
- [ ] 缺失值不转换为假零，未解析比赛不生成不存在的时间线。
- [ ] 英雄池按筛选后的实际样本计算；版本榜另行标注聚合口径，不能冒充当前补丁纯样本。

## 失败与资源限制

- [ ] 网络失败、429 限流、鉴权错误和没有对局是不同状态。
- [ ] 时间预算、每分钟和每日请求预算均生效，不无限重试。
- [ ] 单个查询失败不阻断后续普通聊天。
- [ ] 清缓存不会删除绑定、人设、历史或其他插件数据。
- [ ] 停用插件能释放网络连接；不遗留主动播报任务。
- [ ] 仓库及打包内容没有本机私密配置、真实绑定数据或 API Key。
