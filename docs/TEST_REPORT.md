## 测试驱动的修复

1. **面板入口无法发现**：原目录为 `views/dashboard`，本机框架扫描 `pages/`。先用真实页面发现测试复现失败，再迁移到 `pages/dashboard`；回归通过。
2. **OpenDota 经济数据缺失**：默认战绩字段没有 GPM、XPM 和补刀。按照官方服务端投影接口加入完整字段列表，回归与真实查询通过，统计与 STRATZ 一致。
3. **面板摘要不完整**：嵌套统计原先只能在完整 JSON 查看。增加样本统计、比较摘要及胜负列，并通过浏览器实际查询验证。
4. **窄屏长文本撑宽页面**：范围 JSON 造成文档宽度 1354px、视口仅 360px。增加长文本换行后两者均为 360px。

## 复现

```shell
python -B tests/run_tests.py --astrbot-app /path/to/astrbot/app
node --check pages/dashboard/app.js
python -B tests/live_queries.py
python -B tests/live_queries.py --stratz-token-file .env.stratz-token
```

最后两条会真实联网，前两条不会。`tests/preview_panel.py --astrbot-app /path/to/astrbot/app` 仅用于本机合成数据 UI 验收，监听 `127.0.0.1`，不作为生产服务。
